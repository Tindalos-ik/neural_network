# 卷积神经网络

卷积神经网络（Convolutional Neural Network，CNN）是一类特别适合处理图像等具有空间结构的数据的神经网络



## 动机

在理解 CNN 之前，需要先明白传统全连接网络在处理图像时存在什么问题

> 全连接就是：相邻两层之间，每一个神经元都和下一层的所有神经元相连接

考虑一张 RGB 彩色图片，分辨率为 224 × 224

如果直接把图片展平成向量，那么输入特征就是 224 × 224 × 3  = 150528

假设第一隐藏层有 1000 个神经元，那么仅仅这一层就需要 150528 × 1000 + 1000 = 150529000

也就是差不多 1.5 亿个可训练参数，这太多了



## 算法原理



### 卷积运算

图像和普通特征向量有一个重要区别：图像中向量像素通常具有空间关联性

例如，一条边缘往往由相邻像素之间的高度变化构成

因此，我们不一定需要让每个神经元观察整张图片，而是可以先观察局部区域

这就是卷积神经网络的一个核心思想：局部连接 Local Connectivity



#### 卷积核

![1794997023368](assets/1794997023368.png)

我们先考虑一张 3 × 3 的灰度图像
$$
X=
\begin{bmatrix}
0&3&6\\
1&4&7\\
2&5&8
\end{bmatrix}
$$
定义一个 2 × 2 的卷积核
$$
K=
\begin{bmatrix}
2&0\\
3&1
\end{bmatrix}
$$
卷积核其实就是一个很小的权重矩阵，它会在输入图像上不断滑动，每到一个位置，就与对应的局部区域进行逐元素相乘，再求和



在 CNN 中，卷积核的权重是通过训练学习得到的，其中每一个元素都是可训练参数

训练过程依然是 前向传播 -> 计算损失 -> 反向传播 -> 更新参数

区别在于，全连接层使用权重矩阵对整个输入进行计算，而卷积层使用同一个卷积核，在图像的不同位置重复计算，这种机制称为参数共享

这也是 CNN 能够显著减少参数数量的原因



卷积运算就是使用一组共享的可训练权重，对输入图像的不同局部区域进行加权求和，从而生成特征图（Feature Map）

它保留了空间排列，因此不仅表示“是否出现某种模式”，还保留“这种模式大致出现在哪里”。通常还会经过非线性激活，得到供下一层使用的特征。



### 步幅与填充

现在我们要解决一个问题

> 卷积核每次移动多少距离，如果移动到图像边缘怎么办

这就引出了两个超参数：Stride 和 Padding

* 步幅 Stride，决定卷积核每次移动多少个像素

  步幅越大，卷积核经过的位置越少，输出特征图通常越小，步幅过大也可能跳过一些局部信息

* 填充

  如果输入是 $5\times5 $，卷积核为 $3\times3$，步幅为 1，那么不填充时，输出只有 $3\times3$

  也就是，卷积后图像的空间尺寸缩小了

  如果连续使用多个卷积层，特征图可能很快会变得很小

  Padding 的解决方法是：在输入图像的边缘添加额外的像素，通常填充 0 

  这样可以控制特征图大小，还能让卷积核更充分地处理图像边缘位置



卷积后特征图的尺寸

假设输入图像大小为 $H\times W$，卷积核大小为 $K_H\times K_W$，步幅为 $S_H,S_W$，两侧填充分别为 $P_H,P_W$

那么输出尺寸为
$$
H_{\text{out}}=\left\lfloor\frac{H+2P_H-K_H}{S_H}\right\rfloor+1
$$

$$
W_{\text{out}}=\left\lfloor\frac{W+2P_W-K_W}{S_W}\right\rfloor+1
$$
$\lfloor\cdot\rfloor$ 表示向下取整



在`pytorch`中创建一个卷积神经网络

```python
import torch
import torch.nn as nn

conv = nn.Conv2d(
    in_channels=1,
    out_channels=1,
    kernel_size=3,
    stride=1,
    padding=1
)

x = torch.randn(1, 1, 28, 28)
y = conv(x)

print(y.shape)
# torch.Size([1, 1, 28, 28])
```

PyTorch 的图像张量采用 NCHW 格式

N是批量大小，C是通道数，H，W是空间尺寸



### 多通道卷积

前面我们讨论的都是二维矩阵，比如一张灰度图像，然而真实的彩色图像通常有三个通道 RGB

那么，当输入是三维张量时，卷积核如何工作？



#### 输入通道

一张 RGB 彩色图像可以表示为
$$
X\in\mathbb{R}^{H\times W\times3}
$$
其中

- $H$：图像高度。
- $W$：图像宽度。
- $3$：RGB 三个颜色通道

我们可以将三个二维矩阵沿通道维度堆叠起来

![1794998213936](assets/1794998213936.png)



#### 多通道卷积核

假设输入是 $5 \times 5 \times 3$，我们希望使用一个空间大小为 $3 \times 3$ 的卷积核

这个卷积核需要覆盖输入的全部三个通道，因此它的形状为
$$
K\in\mathbb{R}^{3\times3\times3}
$$
一次卷积计算可以写成
$$
z_{i,j}=
\sum_{c=1}^{3}
\sum_{u=0}^{2}
\sum_{v=0}^{2}
K_{u,v,c}X_{i+u,j+v,c}+b
$$

1. R 通道局部区域与对应的权重矩阵逐元素相乘求和。
2. G 通道做相同计算。
3. B 通道做相同计算。
4. 将三个结果相加，再加上偏置 $b$。



需要注意的是，三个通道的计算结果需要相加，最后只会产生一个输出数值，而不是三个

也就是，一个卷积核，只会产生一张二维特征图

而一个卷积层可以包含多个卷积核，从而可以生成多张二维特征图



### 池化层

卷积层之后，是池化层

为什么需要池化？一张图片经过卷积层之后，得到的是多张特征图，如果后续网络一直处理这个特征图，计算量和内存开销都会比较大

池化层的主要作用是压缩特征图的空间尺寸，尽量保留有用信息



#### 最大池化 Max Pooling

最大池化，即在每个局部区域，选取最大的数值作为输出

假设输入特征图为：
$$
X=
\begin{bmatrix}
1&3&2&4\\
5&6&1&2\\
7&2&8&1\\
3&4&5&9
\end{bmatrix}
$$
使用 $2 \times 2$ 的池化窗口，步幅 $S = 2$

左上角 
$$
max(1,3,5,6) = 6
$$
最终得到
$$
Y_{\max}=
\begin{bmatrix}
6&4\\
7&9
\end{bmatrix}
$$


#### 平均池化 Average Pooling

$$
y=\frac{1}{K_HK_W}\sum_{i=1}^{K_H}\sum_{j=1}^{K_W}x_{i,j}
$$



最大池化保留局部最强响应，平均池化保留局部平均响应



池化层没有可训练参数，但它们仍然参与前向传播和反向传播

例如，最大池化反向传播时，梯度会传递给前向传播中取得最大值的位置；其他非最大值位置的梯度为 0（并列最大值时由具体实现决定）



`pytorch`实现

```python
import torch
import torch.nn as nn

x = torch.randn(1, 16, 32, 32)

max_pool = nn.MaxPool2d(
    kernel_size=2,
    stride=2
)

avg_pool = nn.AvgPool2d(
    kernel_size=2,
    stride=2
)

print(max_pool(x).shape)
# torch.Size([1, 16, 16, 16])

print(avg_pool(x).shape)
# torch.Size([1, 16, 16, 16])
```



### CNN 整体结构

![1795001331549](assets/1795001331549.png)

* 特征提取

  卷积层负责学习局部特征，池化层负责压缩空间尺寸，随着网络加深，特征逐渐从简单模式组合成更复杂的模式

  浅层往往更容易学习局部的明暗变化、边缘和纹理；更深的层可以组合前面的特征，形成对轮廓、部件乃至类别相关结构的响应

* 分类预测

  将前面提取的特征整合起来，计算不同类别的预测分数



> 为什么深层卷积能提取到更复杂的特征？

假设第一层使用 $3×3$ 的卷积核，第一层的某个输出位置，只能观察原始图像中 $3 × 3$ 的局部区域

如果第二层再使用一个 $3 × 3$ 的卷积核，那么第二层的一个输出位置会综合第一层相邻的 $3 × 3$ 个输出，这些第一层输出各自又来自原图中的局部区域

也就是，经过两层卷积，第二层一个位置可以收到原图 $5 × 5$ 区域的影响

每次增加一层卷积，相当于往外扩了一圈

从而多层卷积可以逐渐整合更大范围的信息



`pytorch`实现完整 CNN

```
import torch
import torch.nn as nn

class SimpleCNN(nn.Module):
    def __init__(self):
        super().__init__()

        self.features = nn.Sequential(
            nn.Conv2d(3, 16, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(kernel_size=2, stride=2),

            nn.Conv2d(16, 32, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(kernel_size=2, stride=2)
        )

        self.classifier = nn.Sequential(
            nn.Flatten(),
            nn.Linear(32 * 8 * 8, 10)
        )

    def forward(self, x):
        x = self.features(x)
        x = self.classifier(x)
        return x

model = SimpleCNN()

x = torch.randn(1, 3, 32, 32)
y = model(x)

print(y.shape)
# torch.Size([1, 10])
```

我们现在实际算算，这个卷积神经网络，到底减少了多少参数数量



先看全连接神经网络的

假设输入一张 RGB 图片
$$
X\in\mathbb{R}^{3\times32\times32}
$$
先展平 $32 \times 32 \times 3 = 3072$

假设第一个全连接隐藏层有 128 个神经元

那么共 $ 3072 \times 128  + 128 = 393344$ 个参数，一个全连接层就有 40 万个参数



那么使用卷积神经网络呢？

16个卷积核，每个卷积核的完整尺寸 $ 3 \times 3 \times3$

则一层有 $16 \times (3 \times 3 \times 3  + 1) = 448$ 个参数



不过虽然参数少了，但是计算量还是很多，它们会在图像的许多位置反复参与计算
